插件开发指南

DesktopCoolAPK 的插件系统不追求功能完备，而是把 API 面开得足够大 —— 插件可以换掉整个界面、伪装设备指纹、改写请求、接入第三方服务。

简介

插件是放在 ~/.config/desktopcoolapk/plugins/ 下的普通文件夹， 包含一个 plugin.json 清单和若干 JS / CSS 文件。 主程序启动时扫描并加载被启用的插件。

无需编译 插件是纯 JS / CSS，改完在设置页点「重新扫描」即可生效，不用重启。

快速开始

最小插件只需要两个文件 —— 只改外观：

~/.config/desktopcoolapk/plugins/
└── bluetint/
    ├── plugin.json
    └── style.css

plugin.json

{
  "id":      "dev.me.bluetint",
  "name":    "蓝色调",
  "version": "1.0.0",
  "type":    "theme",
  "style":   "style.css"
}

style.css

:root{
  --green:    #2BA3D4;
  --green-dk: #1E86B0;
}

放好目录后，打开设置与反馈 → 插件，点「重新扫描」，再打开开关。

插件类型

主题 theme
只注入 CSS，改外观。不需要入口 JS。
页面 page
往侧栏加一个新页面，自己渲染内容。
挂件 widget
往现有界面注入按钮或元素，不占新页面。
外壳 shell
接管整个 GUI，用你自己的框架重写界面。
钩子 hook
无界面，只拦截和改写请求、响应。

清单格式

{
  "id":          "dev.example.demo",     // 唯一标识（也是存储命名空间）
  "name":        "显示名",
  "version":     "1.0.0",
  "author":      "作者",
  "description": "一句话说明",
  "type":        "page",                 // theme|page|widget|shell|hook
  "entry":       "index.js",             // 非 theme 必需
  "style":       "style.css",            // 可选
  "icon":        "icon.png",             // 可选
  "permissions": ["api","device","ui","storage","net","sys"],
  "hooks":       ["request","response"]  // 声明后后端才启用钩子
}

数据接口

通用透传

白名单内的任意端点都能调，支持 GET / POST：

await ka.raw("/v6/apk/hotList", { page: 1 });            // GET
await ka.raw("/v6/feed/createFeed", { message: "hi" }, "POST");
await ka.get("/v6/user/profile", { uid: "123" });
await ka.post("/v6/feed/like", { id: "123" });

白名单前缀：

设备伪装

改完立即生效，无需重启 —— User-Agent、X-App-Device、 Token 里的设备指纹会同步变化。 

await ka.device.presets();               // 内置机型列表
await ka.device.get();                   // 当前设备信息
await ka.device.set({ preset: "小米 14 Pro" });
await ka.device.set({ model: "SM-S918B", brand: "samsung", sdkInt: 33 });
await ka.device.random();                // 随机
注意 酷安用数盟（Shuzilm）做设备风控。发动态 / 评论 / 点赞必须携带真实的 数盟设备 ID，否则会被拦为「检测到您的网络环境可能异常」。 这个 ID 需要在官方 App 中获取后在设置页填写，插件无法伪造。

界面控制

注册页面

ka.ui.addPage({
  id: "my-page",
  title: "我的页面",
  render(ka) {
    return `<div class="page-head"><div class="pt">标题</div></div>`;
  }
});

注入到现有界面

ka.ui.onRender((root, ka) => {
  // 每次中栏重绘后调用，root 是中栏容器
  const actions = root.querySelector(".composer-actions");
  if (!actions || actions.querySelector("#myBtn")) return;   // 去重
  const btn = document.createElement("button");
  btn.className = "cbtn";
  btn.id = "myBtn";
  btn.textContent = "我的按钮";
  btn.onclick = () => ka.ui.toast("点到了");
  actions.insertBefore(btn, actions.querySelector('[data-compose="publish"]'));
});

其他

ka.ui.toast("提示");
ka.ui.setTheme("css 字符串");            // 注入样式
ka.ui.modal({ title, body, okText, onOk });
ka.ui.mount("<div>...</div>");            // 往中栏追加
ka.ui.refresh();                         // 刷新界面
ka.ui.replaceShell(html, init);          // 接管整个 GUI
图片加载 WebView 里不能直接跨源取图。用 <img data-src="URL" data-w="240"> 然后调 ka.loadImagesIn(root) 批量加载。

网络与 AI

WebView 的 fetch 受跨域限制，插件发请求统一走本地代理：

const r = await ka.net.request({
  url: "https://api.example.com/x",
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer xxx" },
  body: { a: 1 },       // 对象自动 JSON 序列化
  timeout: 60,
});
// → { ok, status, body, error }

await ka.net.post(url, body, headers);
await ka.net.get(url, headers);

调用大模型

自动适配 OpenAI 与 Anthropic 两种格式：

const text = await ka.net.chat({
  endpoint: "https://api.deepseek.com/anthropic/v1/messages",
  apiKey: "sk-...",
  model: "deepseek-chat",
  messages: [
    { role: "system", content: "你是一个助手" },
    { role: "user",   content: "你好" },
  ],
  temperature: 0.7,
  maxTokens: 2048,
  // format: "anthropic" | "openai"，不传则按 endpoint 自动判断
});

存储

按插件 ID 自动隔离，不会互相干扰：

ka.storage.set("key", { any: "json" });
ka.storage.get("key", 默认值);
ka.storage.remove("key");
ka.storage.keys();

请求钩子

ka.hook.on("request", req => {
  req.headers["X-Custom"] = "value";
  return req;
});

ka.hook.on("response", resp => {
  // 可以在这里过滤广告、改写数据
  return resp;
});
钩子需要在清单里声明 "hooks": ["request"]， 且插件处于启用状态才会生效。

安全边界

  • 插件文件读取限制在插件目录内，禁止 .. 逃逸，单文件上限 4MB
  • /raw 只允许白名单前缀的端点
  • 插件运行在与主界面相同的 JS 上下文，没有沙箱
只装你信任的插件 插件拥有与主程序同等的权限，可以读写本地配置、发起网络请求。
